## Cara Instalasi

1. Clone repo  
   `git clone https://github.com/username/LarasKA.git`
2. Masuk ke direktori proyek  
   `cd LarasKA`
3. Build aplikasi  
   `go build -o laraska`
4. Jalankan  
   `./laraska`
