# Struktur Folder Proyek LARASKA

Proyek ini merupakan implementasi sistem pemesanan tiket kereta berbasis Go dengan struktur folder yang terorganisasi untuk memisahkan tanggung jawab logis dari setiap komponen.

## Struktur Direktori

```
LarasKA
│
└───Controller
│   │   AuthController.go
│   │   Helper.go
│   │   Helper.go
│   │   
│      
│   
└───folder2
    │   file021.txt
    │   file022.txt
```






## Catatan

- **controller/** digunakan untuk mengatur logika bisnis dan routing.
- **model/** berisi struktur data utama (struct) yang merepresentasikan entitas pada sistem.
- **main.go** menjalankan inisialisasi program dan pemanggilan fungsi utama.
Silakan sesuaikan jika ada folder tambahan atau logika khusus lainnya.
